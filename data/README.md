# Dataset

## RadioML 2016.10a

This project uses the RadioML 2016.10a dataset for automatic modulation classification.

The dataset contains IQ (In-phase and Quadrature) signal samples representing multiple modulation types at different Signal-to-Noise Ratio (SNR) levels.

**Dataset:** RadioML 2016.10a
