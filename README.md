##  Project Goal

Develop an intelligent AI system capable of automatically recognizing the modulation type of RF signals from IQ samples using deep learning. The software implementation serves as the foundation for future real-time RF signal identification using RTL-SDR hardware.

---

##  Features

*  Automatic Modulation Classification (AMC)
*  Deep Learning (CNN)
*  RadioML 2016.10a Dataset
*  Model Training & Validation
*  Confusion Matrix
*  Prediction Confidence
*  Precision, Recall & F1-Score
*  Accuracy & Loss Graphs
*  Future RTL-SDR Integration
